# غرفة القيادة — Integration Connector

هذه الخدمة الصغيرة بتشتغل جوه شبكتكم انتم، وبتعمل الحاجات دي:

1. تقرأ بنية قاعدة بياناتكم (أسماء الجداول والأعمدة وأنواعها فقط — مفيش أي بيانات) لما غرفة القيادة تطلبها، عشان الأناليست يبني اللوحات مباشرة على جداولكم بدون ما حد يكتبها يدويًا.
2. تستقبل شكل كل لوحة (العناصر + كويري جاهز لكل عنصر، مكتوب أصلًا على بنية قاعدة بياناتكم دي) وتخزّنه محليًا.
3. لما صفحة العرض (`viewer.html`) تفتح، تنفّذ كويري كل عنصر لحظتها على قاعدة بياناتكم الحية، وترجّع القيم الحالية.
4. لو الأناليست اختار تكاملكم كمصدر بيانات وهو بيبني لوحة جديدة، تنفّذ استعلامات قراءة-فقط حية على قاعدة بياناتكم في تلك اللحظة كمان — مش بس وقت فتح صفحة العرض — عشان يشوف بيانات حقيقية وهو بيبني.

**قاعدة بياناتكم الحقيقية (connection string) متتبعتش لينا أبدًا** — بتتحط هنا بس، في الإعدادات المحلية لهذه الخدمة.

## التشغيل

### تشغيل مباشر (يحتاج .NET 8 SDK مثبّت)
```bash
dotnet run
```
الخدمة هتشتغل افتراضيًا على `http://localhost:5000` (أو المنفذ المحدّد في `ASPNETCORE_URLS`).

### نشر كملف تنفيذي مستقل
```bash
dotnet publish -c Release -o ./publish
cd publish
./IntegrationConnector   # أو IntegrationConnector.exe على ويندوز
```

## الإعداد

عدّل `appsettings.json` (أو استخدم متغيرات بيئة بنفس الاسم، مثلاً `Connector__TargetConnectionString`):

| المفتاح | الوصف |
|---|---|
| `TargetDbProvider` | `SqlServer` أو `Sqlite` — نوع قاعدة بياناتكم الحقيقية. |
| `TargetConnectionString` | نص الاتصال بقاعدة بياناتكم الحية. **سري — لا يُشارك مع أي طرف تاني.** |
| `WriteApiKey` | نفس القيمة اللي دخّلتوها في غرفة القيادة كـ"قيمة المصادقة" لهذا التكامل. بتحمي الاستدعاءات الجاية من عندنا فقط (`/publish` و `/schema`). |
| `WriteApiAuthHeader` | اسم الرأس اللي المفتاح ده بيوصل فيه (افتراضيًا `X-Api-Key`) — لازم يطابق "اسم رأس المصادقة" في غرفة القيادة. |
| `IdentityParameterName` | الاسم الدقيق لمعامل/رأس/كوكي هوية المستخدم، لازم يطابق اللي اتأكد في غرفة القيادة. سيبه فاضي لو كل اللوحات هتكون متاحة للجميع. |
| `LocalStoragePath` | مسار ملف SQLite المحلي اللي بيخزّن شكل اللوحات وقرارات الصلاحيات (مش بياناتكم التجارية — بس شكل اللوحات وقائمة المسموح لهم). |

## نقاط الاتصال اللي بتوفّرها الخدمة دي

كل نقاط الاتصال دي عايشة على نفس القاعدة (base URL) — في غرفة القيادة تحطّوا رابط واحد بس
(مثلاً `http://connector.client-network:5000`) وهي اللي بتشتق الباقي تلقائيًا:

- **نقطة الكتابة**: `POST {base}/publish` — من عندنا بس، محمية بـ `WriteApiKey`.
- **نقطة اكتشاف البنية**: `GET {base}/schema` — من عندنا بس، محمية بنفس `WriteApiKey`؛ بترجّع أسماء جداولكم وأعمدتها وأنواعها فقط (بدون أي بيانات) عشان غرفة القيادة تبني الكويريهات عليها بدل ما حد يكتبها يدويًا.
- **نقطة الاستعلام الحي (وقت البناء)**: `POST {base}/query` — من عندنا بس، محمية بنفس `WriteApiKey`؛ بتاخد استعلام SELECT واحد وتنفّذه على قاعدة بياناتكم الحية وترجّع الصفوف (بحد أقصى 500 صف)، عشان الأناليست يشوف بيانات حقيقية وهو بيبني لوحة على تكاملكم، مش بس وقت النشر.
- **نقطة القراءة**: `GET {base}/dashboards` (القائمة) و `GET {base}/dashboards/{id}` (لوحة واحدة) — من متصفح `viewer.html` مباشرة، بدون مفتاح (الحماية هنا بفلترة الهوية، مش بمفتاح ثابت).
- **نقطة كتابة الصلاحيات**: `POST {base}/permissions` — من متصفح `admin.html` مباشرة؛ من غير مفتاح برضه لنفس السبب: ملف `admin.html` ثابت وموزّع، ومفيش سر ممكن نحطه فيه بأمان. احموا الوصول لصفحة `admin.html` نفسها بحدود شبكتكم الداخلية.
- **نقطة الدليل (اختياري)**: `GET {base}/directory?q=` — راجعة فاضية افتراضيًا؛ عدّلوها لو عايزين بحث فعلي في مستخدميكم/أدواركم.

## ملاحظات أمنية

- كل كويري بيتنفّذ هنا اتفحص مرتين: مرة عند غرفة القيادة قبل النشر، ومرة تانية هنا مستقلة — قراءة فقط (SELECT) دايمًا، أي كويري تاني بيترفض.
- `/schema` بترجّع بنية بس (أسماء وأنواع) — مفيش صف بيانات واحد بيتسرّب منها؛ ومحمية بنفس مفتاح `WriteApiKey`.
- `/permissions` و `/dashboards` و `/directory` من غير مفتاح مركزي عمدًا (ملفات ثابتة موزّعة على المتصفح مفيش مكان آمن تحطّ فيه سر) — احموها بحدود شبكتكم الداخلية بدل كده.
- لو `/publish` و `/schema` و `/query` هيبقوا متاحين من برّه شبكتكم الداخلية، لازم تضبطوا `WriteApiKey` (متسيبوهوش فاضي) وتحطّوا الخدمة ورا HTTPS.
- `/query` بتتفحص إنها SELECT بس بالظبط زي أي كويري تاني، لكنها الوحيدة اللي بتنفّذ استعلامًا "حرًا" (مكتوب لحظتها في محادثة، مش كويري ثابت اتراجع قبل النشر) — لو مش عايزين الإمكانية دي خالص، متختاروش تكاملكم كمصدر بيانات وقت البناء عند الأناليست.
- ملف التخزين المحلي (`connector-storage.db`) بيحتوي بس على شكل اللوحات وقرارات الصلاحيات — مش أي بيانات تجارية حساسة.
