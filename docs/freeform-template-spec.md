# مواصفة تسليم نماذج «تصميم حر» الجاهزة (دفعة النماذج الخارجية)

هذا الملف هو العقد بين من يحوّل القوالب (PowerPoint/تصاميم) إلى نماذج، وبين منصة جيم التي تستقبلها.
التسليم المطلوب **مجلد لكل نموذج** بثلاثة ملفات بالأسماء نفسها حرفيًا، وبلا أي تعديل في كود المنصة:

```
templates/
  <key>/
    template.json   ← بيانات النموذج (بلغتين)
    ar.html         ← الصفحة العربية (RTL)
    en.html         ← الصفحة الإنجليزية (LTR)
```

المرجع العملي: `backend/ChatToDashboard.Api/wwwroot/templates/freeform/corporate-blue.html` (عربي) و`corporate-blue.en.html` (إنجليزي).
أي نموذج جديد يجب أن يسلك سلوكهما نفسه.

## 1) `template.json`

```json
{
  "key": "sl-finance-review",
  "kind": "slides",
  "category": "finance",
  "icon": "📊",
  "name": "مراجعة مالية ربع سنوية",
  "nameEn": "Quarterly Finance Review",
  "description": "ست شرائح: غلاف، ملخص، الإيرادات، المصروفات، التدفق النقدي، الخطوات التالية",
  "descriptionEn": "Six slides: cover, summary, revenue, expenses, cash flow, next steps",
  "sections": [
    { "title": "الغلاف", "titleEn": "Cover" },
    { "title": "الملخص التنفيذي", "titleEn": "Executive Summary" },
    { "title": "الإيرادات (رسم)", "titleEn": "Revenue (chart)", "needsData": true },
    { "title": "المصروفات", "titleEn": "Expenses", "needsData": true },
    { "title": "التدفق النقدي", "titleEn": "Cash Flow", "needsData": true },
    { "title": "الخطوات التالية", "titleEn": "Next Steps" }
  ],
  "brief": "صفحة جاهزة بتصميم ثابت: عند أي تعديل أعد الصفحة كاملة محافظًا على البنية والأنماط وغيّر النصوص والأرقام فقط؛ أرقام الرسوم في كتل JSON بالمعرّفات chart-data-*."
}
```

القواعد:

| الحقل | القيمة |
|---|---|
| `key` | فريد، أحرف لاتينية صغيرة وأرقام وشرطات، بادئة النوع: `sl-` شرائح، `doc-` مستند، `ds-` تصميم، `db-` لوحة، `mo-` حركة. **لا يُغيَّر بعد النشر** (يُحفظ مع تصاميم المستخدمين). |
| `kind` | واحد من `slides` / `doc` / `design` / `dashboard` / `motion`. |
| `category` | واحد من `mgmt` / `sales` / `projects` / `finance` / `hr` / `marketing` / `ops` / `cx` / `general`. |
| `icon` | رمز تعبيري واحد. |
| `name` / `nameEn` | اسم قصير (≤ 40 حرفًا). |
| `description` / `descriptionEn` | سطر واحد (≤ 120 حرفًا). |
| `sections` | **عدد عناصرها = عدد الشرائح/الأقسام في الصفحة بالضبط وبالترتيب نفسه**. `needsData: true` للقسم الذي فيه رقم أو رسم يُملأ من بيانات العميل. |
| `brief` | تعليمات للموديل عند التعديل (اختياري؛ يُستخدم النص الافتراضي أعلاه إن غاب). |

## 2) الصفحتان `ar.html` و`en.html`

- **ملف HTML واحد مستقل بالكامل**: CSS وJS مضمّنان. لا مكتبات خارجية ولا صور خارجية. الاستثناء الوحيد: خطوط Google Fonts عبر `<link>`.
- `ar.html`: `<html lang="ar" dir="rtl">`. `en.html`: `<html lang="en" dir="ltr">` بتخطيط **مرآة** (ما كان يمينًا يصير يسارًا) ونصوص إنجليزية كاملة؛ لا نص عربي يبقى في النسخة الإنجليزية ولا العكس.
- نسبة الشريحة 16:9 بإطار ثابت 1280×720 يُصغَّر ليلائم الحاوية (انظر `.frame` + دالة `fit()` في المرجع). الإطار يجب أن يحمل `flex: none` وإلا يُقص في المعاينة الضيقة.
- الصور: لا صور حقيقية مرخّصة لجهة أخرى. تُستبدل بمكان محجوز `.photo-ph` (نمط هندسي + نص «صورة — استبدلها بصورتك» / «Image — replace with your own») بالقصّ نفسه الذي في التصميم الأصلي.
- **الرسوم البيانية**: SVG يُرسم من كتلة بيانات `<script type="application/json" id="chart-data">` (أو `chart-data-2`، `-3`… عند التعدد) فيُعدَّل الرقم في مكان واحد. الفئة الأولى في اليمين للعربي وفي اليسار للإنجليزي. ممنوع الرسم بمحورين (dual-axis).
- كل نص ظاهر في وسم نصي عادي (`h1/p/span/li/td`) لا داخل SVG `<text>` ولا صور، حتى يعمل «✏️ تعديل النص» من مساحة العمل.
- الألوان ألوان التصميم الأصلي في متغيّرات `:root` (`--navy`, `--blue`…). ألوان الحالة إن وُجدت: أخضر للجيد، أحمر للسيئ، رمادي للثبات، ومع كل لون أيقونة أو نص (لا لون وحده).

### متطلبات نوع «شرائح» (`slides`) تحديدًا

- كل شريحة `<section class="slide">` والنشطة تحمل `active`؛ واحدة ظاهرة في كل مرة.
- دالة عامة `window.goToSlide(i)` (الفهرس من 0) تنتقل وتحدّث العدّاد وتبث `document.dispatchEvent(new CustomEvent('jeem:slide', {detail:{index:i}}))`.
- تنقّل بالأزرار ولوحة المفاتيح (الأسهم، المسافة، PageUp/Down، Home/End) واللمس (سحب)، وشريط تقدّم.
- قبل `</body>`: `<script src="/js/jeem-slides.js"></script>` (شريط المصغّرات من المنصة؛ لا تبنِ شريطًا بنفسك)، وحجز ارتفاعه: `body { padding-bottom: var(--jeem-strip-h, 0px) }` وطرحه من ارتفاع منطقة العرض.
- `@media print`: شريحة لكل صفحة أفقية، بلا تحويلات ولا أزرار.

### متطلبات الأنواع الأخرى

- `doc`: ورقة بيضاء بعرض ≤ 820px في المنتصف، `@page A4` للطباعة، ترويسة وتذييل.
- `design`: صفحة متجاوبة (تعمل على 390px بلا تمرير أفقي).
- `dashboard`: بطاقات مؤشرات + رسوم SVG من كتلة بيانات واحدة + فلاتر.
- `motion`: مشهد SVG/CSS بأزرار تشغيل/إيقاف/إعادة، ويحترم `prefers-reduced-motion`.

## 3) الوصولية والحركة

- `prefers-reduced-motion: reduce` يلغي كل الحركة.
- أزرار بنص أو `aria-label`، تباين كافٍ، وتركيز لوحة المفاتيح ظاهر.

## 4) اختبار القبول الذي ستُفحص به كل حزمة قبل الدخول

1. `template.json` صالح وكل الحقول الإلزامية موجودة، والمفتاح غير مكرر.
2. عدد `<section class="slide">` في الصفحتين = عدد `sections`.
3. الصفحتان تُفتحان في متصفح بلا أخطاء JavaScript، ولا تحمّلان أي مورد خارجي عدا Google Fonts.
4. العربية `dir="rtl"` والإنجليزية `dir="ltr"`، وبلا نص من اللغة الأخرى.
5. `goToSlide` معرّفة و`jeem-slides.js` مضمّن و`--jeem-strip-h` محجوز (للشرائح).
6. بلا تمرير أفقي على 390px.

## 5) التسليم

ملف مضغوط `templates.zip` يحوي مجلد `templates/` بالبنية أعلاه. أي مجلد ناقص ملفًا أو يفشل في اختبار القبول يُرفض بذكر السبب ولا يوقف الباقي.
