# بيانات العرض — صفحات HTML قابلة للتعديل على جيم

صفحة HTML مرفوعة إلى «العروض التقديمية» تبقى ثابتة، لكن أي جزء منها (قائمة مهام، جدول، حالة بنود…) يقدر يحفظ
بياناته في المنصة ويقرأها عند الفتح، بلا إعادة رفع الصفحة. المنصة تتحكم في من يقدر يعدّل.

## الاستخدام داخل الصفحة

```html
<script src="/js/jeem-page.js"></script>
<script>
  const tasks = await jeem.store.get('tasks');           // null إن لم تُحفظ بعد
  await jeem.store.set('tasks', { items: [...] });       // يحفظ (يرفض إن لم تكن لديك صلاحية)
  const me = await jeem.viewer();                        // { signedIn, canEdit, name, editPolicy }
  jeem.onChange('tasks', value => render(value));        // يستطلع التغيير كل 20 ثانية
</script>
```

- المفتاح: حروف وأرقام وشرطات ونقاط (حتى 100 حرف). القيمة أي JSON حتى 256 كيلوبايت. حتى 50 مفتاحًا لكل عرض.
- **التعارض**: `set` يرسل آخر إصدار قرأته تلقائيًا؛ لو عدّل شخص آخر قبلك يرمي خطأ `code === 'conflict'` —
  اعرض رسالة واطلب إعادة التحميل. `set(key, value, { force: true })` يكتب بلا تحقق.
- أخطاء أخرى: `sign_in_required` (السياسة تتطلب الدخول)، `forbidden`، `bad_key`.
- خارج المنصة (فتح الملف محليًا أثناء التأليف) يعمل كل شيء على `localStorage` بنفس العقد.

## البيانات الحيّة (صفحات منشورة من «تصميم حر» أو «منشئ العروض»)

صفحة بُنيت داخل المنصة على بيانات المشروع تُنشر **حيّة**: عند كل فتح تُقدَّم بآخر نتائج استعلاماتها المسجَّلة (تُعاد قراءتها من
قاعدة البيانات، مخزَّنة مؤقتًا 60 ثانية)، وتستطيع وهي مفتوحة طلب التحديث عبر الجسر:

```js
jeem.data.get('q1');                 // {sql, rows, rowCount} من JEEM_DATA
const r = await jeem.data.load();    // يجلب آخر النتائج ويحدّث window.JEEM_DATA ويبث «jeem:data» إن تغيّرت → {changed, refreshedAt}
document.addEventListener('jeem:data', () => render());   // أعد الرسم من JEEM_DATA
const stop = jeem.data.watch(d => render(), 60000);       // استطلاع دوري (الحد الأدنى 15 ثانية)
jeem.data.autoInterval = 0;          // قبل تحميل jeem-page.js: يعطّل الاستطلاع التلقائي (افتراضيًا كل 60 ثانية)
```

لا تُرسل أي جملة SQL من الصفحة؛ المنصة تنفّذ الاستعلامات التي سُجّلت عند البناء فقط، بصلاحيات صاحب التصميم. صاحب العرض
يوقف البيانات الحيّة من قائمة العروض (زر «🟢 حيّة / ⚪ لقطة») فتعود الصفحة إلى لقطة النشر.

## من يستطيع التعديل

من قائمة العروض (لصاحب العرض أو المسؤول): **أي شخص معه الرابط** (الافتراضي)، أو **أعضاء المنظمة** المسجَّلون،
أو **صاحب العرض والمسؤول** فقط. القراءة دائمًا لكل من يفتح الرابط، كما الصفحة نفسها.

## ما تقوله لـ Claude عند تأليف الصفحة

> اجعل قسم «المهام» قابلًا للتعديل، واحفظ بياناته بـ `jeem.store.set('tasks', data)` واقرأها عند التحميل بـ
> `jeem.store.get('tasks')`، مع تضمين `<script src="/js/jeem-page.js"></script>` قبل كود الصفحة. اعرض زر حفظ
> ورسالة عند التعارض (`e.code === 'conflict'`)، وعطّل التعديل إن كانت `(await jeem.viewer()).canEdit` خاطئة.
