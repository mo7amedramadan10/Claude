# 9. التكاملات والامتداد

## 9.1 التكامل مع أنظمة العملاء (لوحات على قاعدة العميل مباشرة)

**ما هي**: بناء لوحة في «جيم» ونشرها لتعمل **على قاعدة بيانات العميل نفسها** داخل نظامه، عبر
خدمة موصل صغيرة يستضيفها العميل ومُسلَّمات HTML جاهزة (صفحة عرض وصفحة إدارة).

**المشكلة التي تحلّها**: عملاء لا يستطيعون نقل بياناتهم إلى المنصة، لكنهم يريدون لوحاتها داخل
أنظمتهم بهويتهم.

**كيف تعمل**:
- اكتشاف مخطط قاعدة العميل عبر الموصل، ومطابقة النماذج عليه؛ أثناء البناء يستعلم المحلل من
  بيانات العميل الحيّة فتظهر صفوف حقيقية فورًا.
- **النشر تصميم لا بيانات**: ما يُرسل للعميل هو العناصر واستعلام كل عنصر؛ الأرقام تُحسب حيًّا عند
  كل فتح على قاعدته، ولا تمر بياناته عبر المنصة.
- هوية بصرية للعميل (ثلاثة ألوان) تُدخل يدويًا أو تُقترح بالموديل أو تُستخرج من شعار/PDF/صورة
  مع تحقق تباين تلقائي.
- تمرير هوية المستخدم من نظام العميل إلى الموصل، وصلاحيات على مستوى الصف إن وفّر العميل جدولها.
- المسلَّمات: صفحة عرض، صفحة إدارة، ومصدر خدمة الموصل (SQL Server أو SQLite عند العميل) مضغوطًا
  ليبنيه وينشره العميل بنفسه.

**ما يميزها**: المنصة تصمّم، والعميل يملك التشغيل والبيانات.

## 9.2 ربط Claude Desktop (مفاتيح وصول شخصية + جسر MCP)

**ما هي**: مفتاح وصول شخصي يصدره المستخدم مرة واحدة، وجسر صغير يجعل Claude Desktop على جهازه
ينشر ويستبدل ويلغي العروض على المنصة مباشرة من المحادثة.

**كيف تعمل**: المفتاح يُخزَّن مجزَّأً (لا يُسترد)، ويعمل بصلاحيات صاحبه نفسها على كل الواجهات؛
المفتاح لا يستطيع إنشاء مفاتيح أخرى. الجسر يقرأ ملف HTML من جهاز المستخدم (بدل إعادة كتابة
صفحة كبيرة حرفيًا) ويرسله.

**القيود الحالية**: المنصة داخلية فالربط من Claude Desktop على جهاز داخل الشبكة فقط.

## 9.3 واجهة للمؤلفين (jeem-page.js)

كل صفحة منشورة أو مرفوعة تضمّن سكربتًا واحدًا فتحصل على: `jeem.store` للبيانات القابلة للتعديل
بإصدارات وتعارض، `jeem.data` للبيانات الحيّة بحدث تغيّر، `jeem.viewer()` لهوية المشاهد، وشريط
مصغّرات للشرائح. خارج المنصة تعمل بالتخزين المحلي بنفس العقد لتأليف الصفحة واختبارها. موثَّق
للمؤلفين في `docs/presentations-data.md`.

---

## 9.4 واجهات HTTP

كل ما في الواجهة متاح كواجهة HTTP (JSON) بالكوكي أو بمفتاح الوصول الشخصي: المصادر، المعاني،
المحادثة، السجل، النماذج، العروض، تصميم حر، النشر، الاستهلاك. ما يجعل الأتمتة والتكامل مع أدوات
أخرى ممكنًا بلا واجهة خاصة.
