# وثيقة مميزات منصة «جيم» (Chat to Dashboard)

هذه الوثيقة تصف **ما تقدر المنصة تعمله** ولماذا هو مهم وما حدوده — ليست دليل استخدام (لا خطوات شاشة
ولا «اضغط على زر كذا»). جمهورها: الإدارة، العملاء المحتملون، فريق المبيعات، ومن ينضم إلى الفريق.

كل ميزة تُعرض ببطاقة موحّدة:

| البند | المعنى |
|---|---|
| **ما هي** | وصف في سطر أو سطرين |
| **المشكلة التي تحلّها** | لماذا وُجدت |
| **كيف تعمل** | الآلية باختصار، بلا تفاصيل شاشة |
| **ما يميزها** | ما يفرّقها عن البديل المعتاد |
| **القيود الحالية** | بصراحة، حتى تبقى الوثيقة صادقة |
