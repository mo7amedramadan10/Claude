# 1. نظرة عامة

## ما هي «جيم»

«جيم» منصة تحليلات وتأليف بالذكاء الاصطناعي تعمل داخل شبكة المؤسسة: المستخدم يرفع بياناته
(ملفات Excel/CSV، ملفات PDF، أو أنظمة خارجية)، ثم **يطلب بالعربية** ما يريده، فتُنتج له المنصة
لوحة متابعة، أو عرضًا تقديميًا، أو صفحة ويب مصمَّمة، أو إجابة تحليلية — من بياناته الحقيقية،
قابلة للتعديل والنشر والمشاركة برابط.

الفكرة الجوهرية: **من البيانات الخام إلى مخرج جاهز بجملة واحدة**، مع إبقاء الإنسان مسيطرًا على
كل خطوة (تصحيح، تعديل يدوي، إعادة بناء جزئية، نشر بصلاحيات).

## لمن

- **الإدارة ومتخذو القرار**: لوحات وعروض من بيانات محدَّثة بلا انتظار فريق تقني.
- **المحللون ومديرو المشاريع**: استكشاف البيانات بالسؤال، نماذج جاهزة لأكثر من 240 لوحة، تصدير
  إلى PowerPoint.
- **فرق التواصل والعرض**: عروض وصفحات بهوية المؤسسة (ألوانها وخطوطها وقالب PowerPoint الخاص بها)،
  تُنشر برابط عام وتبقى حيّة ببياناتها.
- **المؤسسة كجهة**: تعدد المنظمات والمشاريع في منصة واحدة، مع عزل كامل لبيانات كل مشروع.

## المكوّنات الرئيسية

| المكوّن | ما يقدمه |
|---|---|
| **المصادر** | رفع الملفات، ربط ملف برابط عام ومزامنته، أنظمة خارجية، فهم آلي لمعنى كل عمود |
| **المحادثة واللوحات** | سؤال حر أو نموذج من الكتالوج ← لوحة مؤشرات ورسوم وجداول بفلاتر، تُحفظ وتُنشر وتُصدَّر |
| **اللوحات التفاعلية** | 22 محركًا متخصصًا (كانبان، مسار مبيعات، خزينة، مخاطر موردين…) تعمل على بيانات المشروع |
| **الاستفسارات والمحلل الذكي** | إجابات نصية وتحليلات بالمحادثة على البيانات نفسها، بنتائج قابلة للتصدير وإعادة التحقق |
| **منشئ العروض** | عرض تقديمي من مواصفة منظّمة: شرائح من البيانات، هوية المشروع، قالب PowerPoint الحقيقي، تصدير PPTX |
| **تصميم حر** | صفحات ويب كاملة بالذكاء الاصطناعي (مستند، شرائح، تصميم، لوحة، حركة) أو رفع صفحة/عرض كما هو |
| **النشر والمشاركة** | روابط عامة مقروءة، عزل أمني للصفحات المنشورة، بيانات حيّة، أجزاء قابلة للتعديل، مساعد صوتي |
| **الذكاء الاصطناعي** | تعدد المزوّدين (OpenAI، Claude، Ollama محلي)، مفاتيح مشفّرة، تتبع كامل لكل نداء وتكلفته |
| **الإدارة** | منظمات ومشاريع وأدوار، مكتبة نماذج قابلة للتخصيص، تكاملات مع أنظمة العملاء |

## كيف تعمل المنصة (الصورة الكبيرة)

1. **تحميل**: كل ملف يُحوَّل إلى جدول في قاعدة SQL Server مركزية، داخل مخطط خاص بالمشروع. كل
   المستخدمين على أجهزة مختلفة يرون البيانات نفسها محدَّثة، ولا أحد يحتاج نسخة محلية من الملف.
2. **فهم**: طبقة معنى تحلّل كل عمود (هل هو إيراد؟ تاريخ؟ حالة صفقة؟) من قيمه لا من اسمه فقط،
   وتتعلّم من تصحيحات المستخدمين.
3. **طلب**: المستخدم يكتب بالعربية. الموديل يرى ملف تعريف البيانات (الجداول، الأعمدة، معانيها،
   عيّنات) لا البيانات كلها.
4. **تنفيذ محكوم**: الموديل لا يصل إلى القاعدة مباشرة؛ يطلب استعلامات **قراءة فقط** تمر على مدقّق
   يرفض أي تعديل أو وصول خارج جداول المشروع، ثم تُنفَّذ بصلاحيات المستخدم نفسه.
5. **مخرج منظّم**: الناتج مواصفة (لوحة، عرض، صفحة) تُرسم في المتصفح، فتبقى قابلة للتعديل
   اليدوي والتصدير وإعادة البناء الجزئي بلا إعادة كل شيء.
6. **نشر**: ما يُنشر يخرج برابط عام في صفحة معزولة أمنيًا، ويمكن أن يبقى حيًّا ببيانات المصدر.

## ما يميز «جيم» كمنصة

- **بياناتك تبقى عندك**: المنصة تُستضاف داخل شبكة المؤسسة أو سحابتها (Azure)، والذكاء الاصطناعي
  يرى تعريف البيانات ونتائج الاستعلامات لا الملفات نفسها. يمكن تشغيلها بموديل محلي (Ollama) بلا
  أي مزوّد خارجي.
- **الصدق قبل الجمال**: لا أرقام مخترعة. العنصر الذي لا بيانات له يظهر بسبب واضح («يحتاج عمود
  الميزانية وهو غير موجود») بدل قيمة وهمية، والجدوى تُحسب قبل البناء لا بعده.
- **عربي أولًا**: واجهة وتنسيق أرقام وتصميم RTL من الأساس، ونماذج مكتوبة للسياق المحلي، ومساعد
  صوتي بالعربية.
- **من الاستكشاف إلى التسليم في مكان واحد**: السؤال ← اللوحة ← العرض ← الصفحة المنشورة ← مساعد
  يشرحها للجمهور، كلها على البيانات نفسها بلا تصدير واستيراد بين أدوات.
- **قابلية التدقيق**: كل نداء للموديل مسجَّل بالنص الكامل المرسل والمستلم وكل استعلام نُفِّذ،
  وتكلفته وزمنه، فيمكن مراجعة أي نتيجة إلى أصلها.

## القيود العامة (على مستوى المنصة)

- قاعدة البيانات SQL Server فقط (محلية، Express، أو Azure SQL).
- الملف الواحد يُحمَّل كجدول واحد (ورقة واحدة من Excel)؛ تعدد الأوراق يحتاج ربطًا لكل ورقة.
- جودة المخرجات الذكية تعتمد على الموديل المختار؛ الموديلات المحلية الصغيرة أقل التزامًا بالقواعد
  من موديلات OpenAI/Claude الحديثة.
- بعض الميزات اختُبرت على خوادم وهمية فقط وليس على مزوّد حقيقي (مُفصَّلة في الملحق).

## الصفحة الرئيسية للمنصة

- **ما هي**: أول ما يراه الزائر على عنوان المنصة: صفحة تعريفية بأسلوب العرض الاستراتيجي موجّهة للإدارة العليا، بالعربية الفصحى
  والإنجليزية بزر تبديل، وفيها زر «تسجيل الدخول» الذي ينقل إلى شاشة الدخول.
- **محتواها**: التحدي، والحل بثلاث خطوات، والمنتجات الستة في «تصميم حر» (المستندات، العروض التقديمية، التصاميم، اللوحات، المشاهد
  المتحركة، لوحات المتابعة) ولكل منها لقطة وقيمته ومثال استخدام وعدد قوالبه، ثم «قالب لكل شيء»، وما يميّز المنصة، والحوكمة والأمان،
  والأثر بأرقام مقيسة فعلًا.
- **السلوك**: المستخدم المسجَّل دخوله يذهب إلى المنصة مباشرة، والصفحة متاحة للجميع على `/home`. الصور لقطات من المنصة بأرقام توضيحية،
  بلا أي بيانات عملاء.
