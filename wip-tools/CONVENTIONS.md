أنت تحوّل مجلد صور شرائح (1280×720 لكل صورة) إلى نموذج HTML ثنائي اللغة لمنصة «جيم». كل ما تحتاجه هنا؛ لا تعدّل أي ملف في المشروع خارج مجلد النموذج.

## 2) الخطوات لكل نموذج
1. اعرض **كل** صور المجلد بأداة Read (صورة صورة) وسجّل لكل شريحة: الكتل ومواضعها بالبكسل (الصورة 1280×720 = إحداثيات الإطار نفسها)، الألوان، أحجام الخطوط التقريبية، النصوص حرفيًا، الصور الفوتوغرافية وحدودها، الرسوم البيانية وقيمها.
2. اكتب `T/tpl/<key>.py` بالصيغة أدناه.
3. اقصّ الصور الفوتوغرافية بـ `crop.py` (مربع القصّ بإحداثيات الصورة الأصلية).
4. `python3 -I T/build.py <key>` ثم `node T/check.js <key>`. أصلح أي ✗ حتى تمرّ كل البنود.
5. افتح صور المقارنة `cmp-NN.png` **لكل شريحة** بأداة Read وقارن: المواضع، النسب، الألوان، الالتفاف، الخطوط، الصور. أصلح الفروق الواضحة وأعد البناء والفحص (عادة 2–3 دورات). النسخة الإنجليزية يجب أن تطابق الأصل، والعربية مرآتها.
6. لا تعمل git إطلاقًا (لا add ولا commit). المنسّق يجمع ويلتزم.
7. أعد تقريرًا قصيرًا: المفتاح، عدد الشرائح، نتيجة check.js، عدد الصور في assets، وأي فرق متعمد عن الأصل وسببه.

## 3) صيغة ملف `T/tpl/<key>.py`
```python
KEY = 'sl-…'                      # من الفهرس
TITLE = {'ar': '…', 'en': '…'}   # عنوان الصفحة <title>
COMMENT = '…'                     # وصف بالعربية يُكتب أول <style>
VARS = '--ink:#…; --accent:#…; --bg:#FFFFFF; …'   # ألوان التصميم الأصلي (إلزامي: --ink و--accent و--bg)
STYLE = """  .s1 .ttl { position:absolute; top:…px; inset-inline-start:…px; … }"""   # CSS الشرائح كلها
SLIDES = [ '<h1 class="ttl">§TTL1§</h1> …', '…' ]   # HTML داخل .frame لكل شريحة بالترتيب؛ النصوص رموز §اسم§
STR = {'ar': {'TTL1': '…'}, 'en': {'TTL1': '…'}}   # كل الرموز بالضبط في اللغتين
TEMPLATE = { 'key': KEY, 'kind': 'slides', 'category': '…', 'icon': '…', 'name': '…', 'nameEn': '…',
             'description': '…', 'descriptionEn': '…', 'sections': [ {'title': '…', 'titleEn': '…', 'needsData': True}, … ], 'brief': '…' }
# اختياري:
GLOBAL_DEFS = '<defs>…</defs>'       # تدرّجات/أنماط SVG مشتركة تُوضع خارج الشرائح (لأن الشرائح المخفية لا تُرسم تدرّجاتها)
JSON_BLOCKS = {'chart-data': {'ar': {...}, 'en': {...}}}   # كتل <script type="application/json" id="…"> (قيمة بلغتين أو قيمة واحدة)
EXTRA_SCRIPT = """  function drawChart(){ … } drawChart();"""   # JS يُنفَّذ قبل التنقّل (المتغيّر RTL متاح)
FONTS = {'ar': '<link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;700&display=swap" rel="stylesheet">', 'en': '…'}
FONT_STACK = {'ar': "'Cairo', sans-serif", 'en': "'Montserrat', sans-serif"}
```
- الافتراضي: Tajawal للعربية وInter للإنجليزية. غيّرهما فقط إن كان خط الأصل مختلفًا بوضوح (مثل Montserrat/Poppins/Playfair) وبخط عربي مناسب (Cairo، Almarai، IBM Plex Sans Arabic، Noto Kufi Arabic، Changa).
- الصنف `.sN` على الإطار (`.frame.s1`…) يُضاف تلقائيًا؛ استخدمه لتقييد CSS كل شريحة. الأنماط المشتركة بين الشرائح تُكتب مرة.
- `§اسم§` يُستبدل من `STR[lang]`؛ أي رمز بلا قيمة يوقف البناء. الرموز الجاهزة: `§LANG§`، `§DIR§`.
- يُحقن تلقائيًا: الإطار 1280×720 و`fit()`، التنقّل والأزرار ولوحة المفاتيح واللمس وشريط التقدّم، `goToSlide`، حدث `jeem:slide`، `jeem-slides.js`، الطباعة، `--jeem-strip-h`. **لا تكتب شيئًا من هذا بنفسك.**

## 4) قواعد التخطيط (الأهم)
- **إحداثيات مطلقة** داخل الإطار: كل كتلة `position:absolute` بـ `top` و`inset-inline-start` (أو `inset-inline-end`) و`width`/`height` مأخوذة من الصورة. لا `left/right` ولا `margin-left/right` ولا `text-align:left/right`: استخدم `inset-inline-start/end`، `margin-inline-*`، `padding-inline-*`، `text-align:start/end`، `border-inline-*`، `border-start-start-radius`… فتنعكس الصفحة العربية تلقائيًا.
- التدرّجات الأفقية والأشكال غير المتماثلة (`clip-path`، مثلثات، أسهم أفقية، صور بقصّ مائل): اكتبها للنسخة الإنجليزية، ثم اعكسها للعربية بقاعدة `html[dir="rtl"] .x { transform: scaleX(-1); }` على الشكل الزخرفي فقط (لا على النص) أو بقيم بديلة تحت `html[dir="rtl"]`. الأشكال المتماثلة لا تحتاج شيئًا.
- أحجام الخطوط: اقرأها من الصورة (عنوان غلاف 56–80px، عنوان شريحة 36–48px، عنوان فرعي 20–26px، نص 15–18px، صغير 12–14px). الأوزان: بالعربية استخدم 700/800 للعناوين الغامقة و400/500 للنصوص.
- النصوص: الإنجليزية **حرفيًا كما في الصورة** (بما فيها Placeholder وsample text والأرقام والأخطاء الإملائية الموجودة في الأصل؛ لا تصحّحها). العربية ترجمة احترافية بالفصحى؛ الأرقام والرموز ($18.4M، 31%، FY 26) تبقى كما هي؛ «This is a sample text. Add your desired text here.» → «هذا نص توضيحي. أضف النص المطلوب هنا.»؛ «Placeholder» → «عنوان نائب»؛ «Add subheading here» → «أضف عنوانًا فرعيًا هنا»؛ «Lorem ipsum…» → نص توضيحي عربي بالطول نفسه. لا نص إنجليزي في ar.html ولا عربي في en.html (الفحص يرفضهما). لا تختلق محتوى غير موجود في الصورة.
- كل نص ظاهر في وسم HTML عادي (`h1/h2/p/span/li/td`)، **ممنوع** `<text>` داخل SVG، وممنوع النص داخل الصور.
- **الصور الفوتوغرافية**: تُقصّ من صورة الشريحة بإحداثياتها الدقيقة (`crop.py`) وتُستخدم بـ `<img src="/templates/freeform/<key>/assets/<name>.jpg" alt="…" style="…object-fit:cover">` بالمسار المطلق هذا بالضبط. الشكل (زوايا مدوّرة، دائرة، قصّ مائل) على `<img>` نفسه بـ `border-radius`/`clip-path`. إن تعذّر القصّ النظيف (نص فوق الصورة أو شكل معقد) اقصّ أكبر مستطيل نظيف ممكن، وفي أسوأ الحالات ضع `.photo-ph` (انظر المرجع) مع ذكر ذلك في التقرير. صورة مكررة في عدة شرائح تُقصّ مرة واحدة. لا data URL أبدًا.
- **الشعارات والأيقونات**: أيقونات بسيطة تُرسم SVG مضمّنًا (`viewBox="0 0 24 24"` بـ `fill="currentColor"`) أو رمز تعبيري مناسب؛ الشعارات المجردة (شكل هندسي) تُرسم SVG تقريبيًا. لا تقصّ الأيقونات كصور.
- **الرسوم البيانية**: SVG يُرسم بـ JS من `JSON_BLOCKS` (`chart-data`، `chart-data-2`…) بقيم مقروءة من الصورة (تقديرًا إن لم تكن مكتوبة)، ألوان السلاسل من الأصل، الفئة الأولى في جهة البداية (`RTL` للعربية). التسميات والأرقام الظاهرة داخل الرسم تُرسم كـ `<text>` داخل SVG مسموحة هنا فقط للمحاور والقيم (ليست نصوص محتوى). ممنوع المحوران. القسم الذي فيه رقم أو رسم يُعلَّم `needsData: true`.
- **الأشكال**: مستطيلات/دوائر/خطوط بـ CSS؛ المعقد (أقماع، أهرام، دوائر ثلاثية الأبعاد، أسهم، خرائط) SVG مضمّن بتدرّجات في `GLOBAL_DEFS`.
- الخلفيات: لون/تدرّج CSS. خلفية فوتوغرافية كاملة = صورة مقصوصة من الشريحة بإزالة النصوص المتداخلة قدر الإمكان (اقصّ منطقة خالية من النص وامددها بـ `object-fit:cover`)، أو الجزء النظيف منها.
- إن تكررت شريحة بنفس التخطيط (عناوين الأقسام مثلًا) أعد استخدام CSS نفسه بأصناف مشتركة.

## 5) template.json
- `category` واحد من: `mgmt / sales / projects / finance / hr / marketing / ops / cx / general` بحسب موضوع النموذج (نماذج الشركات والعروض العامة → `general`، الاستراتيجية والإدارة → `mgmt`، الأقماع والمبيعات → `sales`، التسويق والعلامة → `marketing`، المالية → `finance`، الموارد البشرية والتدريب → `hr`، المشاريع → `projects`، العمليات والجودة → `ops`، خدمة العملاء → `cx`).
- `icon` رمز تعبيري واحد. `name/nameEn` ≤ 40 حرفًا (اسم القالب بلا كلمة PowerPoint Template). `description/descriptionEn` ≤ 120 حرفًا تصف الشرائح.
- `sections`: عنصر لكل شريحة بالترتيب نفسه بعنوانها العربي والإنجليزي، `needsData: true` لما فيه رقم/رسم.
- `brief`: جملة بالعربية تلزم الموديل بالحفاظ على البنية والأنماط وتغيير النصوص والأرقام فقط (وتذكر كتل chart-data إن وُجدت).

## 6) معايير القبول قبل التسليم
`check.js` يجب أن يطبع «✓ كل البنود مرّت»، وصور المقارنة تُظهر مطابقة في: مواضع الكتل (±10px)، الألوان، الخطوط والأوزان، التفاف النص، الصور في مكانها، الرسم بالقيم نفسها، وبلا عناصر مقطوعة أو متداخلة. لا تسلّم نموذجًا فيه ✗.

## 7) قرارات موحّدة من الدفعات السابقة (التزم بها)
- شعار جهة حقيقية في الأصل (مثل SlideModel.com) يُستبدل بشعار عام محايد مع «Logo» / «الشعار»؛ «YOUR COMPANY LOGO HERE» يبقى كما هو ويُترجم.
- الاختصارات اللاتينية في العربية: حروف النموذج المفردة أو حرفان (A/I/D/A، 4Ps) تبقى، وما هو 3 أحرف فأكثر يُكتب بالعربية (SWOT → سوات، TAM/SAM/SOM → الكلي/المتاح/الممكن). البريد والمواقع تُستبدل بوصف عربي، والهواتف تبقى داخل dir="ltr".
- الأرقام والعملات في العربية داخل `<bdi dir="ltr">` حتى لا ينقلب ترتيبها.
- إزالة نص مطبوع فوق صورة (inpainting) مسموحة بسكربت في مجلدك المؤقت، والمخرج يُكتب في assets النموذج فقط.
- لا تترك ملفات مؤقتة في مجلد النموذج ولا في مجلد الأدوات.
